# 反诈资金图谱平台 - 数据字典

## 文档说明

本文档详细说明了反诈资金图谱项目中涉及的所有数据表结构、字段含义及取值范围。本项目基于真实脱敏后的金融交易数据，用于识别和分析诈骗风险账户网络。

**数据概况**

- 账户总数：11,087个
- 交易记录：904,395条
- 风险账户标签：嫌疑人59个，受害人1,153个，正常账户9,875个
- 本地交易时间范围：2025年7月1日 02:15:01 - 2025年12月31日 20:28:55
- 规范化数据版本：`d02568e53fa4e3e3`

## 4. 数据关系说明

### 表关系

```
accounts (1) ----< (N) transactions (付款方)
accounts (1) ----< (N) transactions (收款方)
accounts (1) ---- (1) labels
```

- **账户表 ↔ 标签表**：一对一关系，每个账户有唯一的风险标签
- **账户表 ↔ 交易表**：一对多关系，一个账户可以作为付款方或收款方参与多笔交易
- **交易表构成有向图**：payer_account_id → payee_account_id 形成有向边，amount为边权重
- **交易事件边**：一笔规范化交易对应一条事件边，共904,395条
- **聚合账户对边**：相同付款方和收款方聚合为一条有向边，共106,250条

### 数据完整性

- 所有账户在标签表中都有对应记录
- 交易表中的账户ID均可在账户表中找到
- 核心字段（ID、时间、金额）无缺失值
- 部分扩展字段预留但暂无数据

## 5. 数据使用建议

### 图谱构建

- 使用`payer_account_id`和`payee_account_id`构建资金流向有向图
- 分别保留交易笔数、签名金额和绝对金额作为边权重
- 结合`event_time_utc`进行时序图分析
- 图密度和入/出度按唯一有向账户对计算，不得使用交易事件数替代边数

### 特征工程
- **账户维度**：开户时长、客户类型、地区分布
- **交易维度**：交易频率、交易金额统计（总额、均值、最大值）、交易时间模式
- **图特征**：入度/出度、PageRank、社区检测、最短路径等图算法特征
- **时间特征**：交易时段分布、工作日/周末模式、交易间隔

### 风险识别
- **嫌疑人特征**：可能表现为大量入账、快速转出、与多个受害人账户关联
- **受害人特征**：可能表现为单次或少量大额转出、与嫌疑人账户直接交易
- **正常账户**：交易模式相对稳定，金额分布合理

### 模型评估

- 注意标签不平衡问题（嫌疑人仅0.5%）
- 建议使用F1-Score、PR-AUC等指标，而非单纯的准确率
- 使用任务一提供的顺序分区和28天隔离期；在标签时间缺失时只做静态回溯

- 核心字段完整，无缺失值
- 部分扩展字段（channel_type、transaction_type等）预留但未填充
- 标签数据完整，每个账户都有明确的风险分类

### 数据一致性

- 交易时间范围为2025年7月1日至12月31日（Asia/Shanghai）
- 账户数量在各表间保持一致
- 交易数量与说明文档一致（904,395条）
- 交易端点均可在账户表中找到，交易ID无重复
