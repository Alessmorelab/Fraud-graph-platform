# 反诈资金图谱平台 - 数据字典

## 文档说明

本文档详细说明了反诈资金图谱项目中涉及的所有数据表结构、字段含义及取值范围。本项目基于真实脱敏后的金融交易数据，用于识别和分析诈骗风险账户网络。

**数据概况**
- 账户总数：11,087个
- 交易记录：904,395条
- 风险账户标签：嫌疑人59个，受害人1,153个，正常账户9,875个
- 数据时间范围：2025年10月31日 - 2025年11月30日

---

## 1. 账户表 (accounts.parquet)

账户表包含所有参与交易的账户基本信息。

**文件路径**: `var/normalized/d02568e53fa4e3e3/accounts.parquet`  
**记录数**: 11,087条

### 字段说明

| 字段名 | 数据类型 | 业务含义 | 取值范围/示例 | 备注 |
|--------|----------|----------|---------------|------|
| `account_id` | string | 账户唯一标识符 | "1", "5662", "5660" | 已脱敏处理 |
| `tenure_months` | float64 | 开户时长（月） | 4.94 ~ 410.90<br>平均值：103.40<br>中位数：86.35 | 单位为月，反映账户活跃时长 |

### 业务说明

- **开户时长分布**：账户开户时长从4.94个月到410.90个月不等，平均开户时长约8.6年，说明大部分账户为长期稳定账户
- **客户类型分布**：对公账户占比87.7%，对私账户占比12.3%，符合金融交易以企业间往来为主的特征
- **地区分布**：地区编码633的账户最多（2,727个），显示出明显的地域聚集特征

- **交易金额特征**：

  - 平均值远高于中位数，存在大额交易拉高均值

- **数据覆盖**：

  - 这些字段可在后续数据补充后用于更细粒度的分析

## 4. 数据关系说明

### 表关系

```
accounts (1) ----< (N) transactions (付款方)
accounts (1) ----< (N) transactions (收款方)
accounts (1) ---- (1) labels
```

- **账户表 ↔ 标签表**：一对一关系，每个账户有唯一的风险标签
- **账户表 ↔ 交易表**：一对多关系，一个账户可以作为付款方或收款方参与多笔交易
- **交易表构成有向图**：payer_account_id → payee_account_id 形成有向边，amount为边权重

### 数据完整性

- 所有账户在标签表中都有对应记录
- 交易表中的账户ID均可在账户表中找到
- 核心字段（ID、时间、金额）无缺失值
- 部分扩展字段预留但暂无数据

## 5. 数据使用建议

### 图谱构建
- 使用`payer_account_id`和`payee_account_id`构建资金流向有向图
- 以`amount`作为边权重，反映资金流动规模
- 结合`event_time_utc`进行时序图分析

### 特征工程
- **账户维度**：开户时长、客户类型、地区分布
- **交易维度**：交易频率、交易金额统计（总额、均值、最大值）、交易时间模式
- **图特征**：入度/出度、PageRank、社区检测、最短路径等图算法特征
- **时间特征**：交易时段分布、工作日/周末模式、交易间隔

### 风险识别
- **嫌疑人特征**：可能表现为大量入账、快速转出、与多个受害人账户关联
- **受害人特征**：可能表现为单次或少量大额转出、与嫌疑人账户直接交易
- **正常账户**：交易模式相对稳定，金额分布合理

### 模型评估
- 注意标签不平衡问题（嫌疑人仅0.5%）
- 建议使用F1-Score、PR-AUC等指标，而非单纯的准确率
- 考虑时间序列划分，避免标签泄露
