### 2. PR-AUC对比（⭐ 比赛明确要求）

| 模型 | PR-AUC | vs Behavior | 绝对提升 | 相对提升 | 状态 |
|------|--------|-------------|---------|---------|------|
| Behavior基线 | 0.0155 | - | - | - | 基线 |
| Profile中间 | 0.0696 | ↑ | **+0.0541** | **+349%** | ✅✅✅ |
| Combined最佳 | 0.0777 | ↑ | **+0.0622** | **+401%** | ✅✅✅ |

**关键发现**：
- Combined模型PR-AUC达到0.0777，相比基线提升401%
- **远超比赛要求的20%提升**，是要求的**20倍**
- 在极度不平衡场景下（0.53%正样本率），PR-AUC从0.0155提升到0.0777是显著进步

**为什么PR-AUC绝对值看起来较低？**

这是极度不平衡数据的正常现象：
```
正样本占比：0.53%（59/11,087）
不平衡比：1:187

在随机基线下，PR-AUC ≈ 正样本占比 = 0.0053
Behavior的0.0155已是随机的2.9倍
Combined的0.0777已是随机的14.6倍 ✅
```

**比赛要求验证**：
```
要求：PR-AUC较基线提升不低于20%
实际：+401%
结论：✅ 远超要求（超标381个百分点）
```

## 🔬 深度分析：为什么Combined优于Behavior？

### 1. 特征集差异分析

| 特征集 | 特征类别 | 典型特征 | 特征数 |
|--------|---------|---------|--------|
| **Behavior** | 交易行为特征 | 交易笔数、金额、时间模式、对手方数量等 | 22个 |
| **Profile** | 账户静态画像 | 开户时长、地区、客户类型 | 5个 |
| **Combined** | Behavior + Profile | 全部特征 | 27个 |

**Behavior特征示例**：
- 出入账笔数、金额统计
- 对手方数量
- 夜间交易笔数
- 自转账次数
- 同日进出天数
- 快速周转率

**Profile特征示例**：
- `tenure_months`：开户时长
- `region_code`：地区编码
- `customer_type`：客户类型（对公/对私）
- `has_transactions`：是否有交易

### 2. 性能增益来源分解

```
性能提升路径（ROC-AUC）：

Behavior单独: 0.8162
    ↓ +10.81pp
Profile单独: 0.9243  ← 5个特征就能达到92.4%！
    ↓ +0.98pp
Combined: 0.9341     ← 行为特征提供额外增益

结论：
✅ 静态画像是最强信号（贡献10.81pp）
✅ 行为特征提供额外1pp增益（精细化排序）
```

**为什么Profile如此强大？**

分析数据分布发现：
```
风险账户特征：
- 1,212个风险相关账户中，1,203个为对私账户（99.3%）
- 可能存在开户时间、地区等维度的显著差异

潜在原因：
⚠️ 账户画像可能学习了客户类型和数据缺失模式的捷径
⚠️ 高AUC不等于强大的资金风险识别能力
⚠️ 这是数据特征，不是模型缺陷
```

### 3. 召回率相同的反直觉现象

**观察**：Profile和Combined在Top5%召回率上完全相同（57.6%）

| 指标 | Profile | Combined | 差异 |
|------|---------|----------|------|
| ROC-AUC | 0.9243 | 0.9341 | +0.98pp |
| PR-AUC | 0.0696 | 0.0777 | +0.0081 |
| Top5%召回率 | 57.6% | 57.6% | **0** ← 相同！ |
| Lift@5% | 11.51x | 11.51x | **0** ← 相同！ |

**解释**：

1. **捕获的是同一批风险账户**
   - Profile和Combined在Top5%范围内识别出的是相同的34个风险账户
   - 行为特征没有发现新的风险账户

2. **行为特征的作用是精细化排序**
   - ROC-AUC提升说明Combined在全局排序上更准确
   - PR-AUC提升说明Combined在高分区间的精确率更高
   - 但在Top5%这个粗粒度上，两者结果一致

3. **Behavior错过的风险账户**
   - Behavior仅发现9个（15.3%），错过25个Profile能找到的
   - 这25个风险账户主要通过**静态画像特征**区分
   - 它们的交易行为可能不够异常，但账户属性有明显特征

**业务启示**：
```
✅ Combined是最优选择（兼顾全局排序和高分精确率）
✅ Profile已经捕获了核心风险信号
✅ Behavior单独使用会漏掉大量风险账户
⚠️ 需要警惕画像特征的"捷径学习"问题
```

## 💡 关键洞察与建议

### 1. 模型选择建议

**生产环境推荐**：使用Combined模型（27e53f783dde8968）

**理由**：
- ✅ 全局排序能力最强（ROC-AUC 0.9341）
- ✅ 高分区间精确率最高（PR-AUC 0.0777）
- ✅ 召回率达标（57.6%）
- ✅ 可解释性强（逻辑回归，系数直接可读）
- ✅ 符合监管要求

**不推荐**：单独使用Behavior模型
- ❌ ROC-AUC不达标（0.8162 < 0.85）
- ❌ 召回率严重不足（15.3% << 50%）
- ❌ 会漏掉84.7%的风险账户

### 2. Profile特征的警示

**现象**：Profile仅用5个特征就达到0.9243 AUC

**潜在风险**：
```
⚠️ 捷径学习（Shortcut Learning）
  └─ 模型可能学习了客户类型等易得特征
  └─ 1,203/1,212（99.3%）风险账户为对私账户
  └─ 高AUC可能来自数据分布偏差，而非真实风险识别能力

⚠️ 生产风险
  └─ 如果客户类型分布变化，模型性能可能急剧下降
  └─ 可能对某些客户群体产生系统性偏差
  └─ 监管合规风险（是否构成客户歧视）
```

**建议**：
1. 进行特征重要性分析，确认`customer_type`的权重
2. 按客户类型分层评估模型性能
3. 监控生产环境中客户类型分布变化
4. 考虑去除或降权`customer_type`特征后的性能

### 3. Behavior特征的价值

虽然Behavior单独使用不达标，但它提供了重要价值：

✅ **增量价值**：在Profile基础上提升1pp ROC-AUC
✅ **稳健性**：不依赖静态画像，对分布变化更鲁棒
✅ **可解释性**：交易行为特征更贴近业务直觉
✅ **通用性**：适用于画像特征不可用的场景

**建议保留所有行为特征作为Combined模型的一部分。**
