## 🔬 消融实验：特征集对比

系统训练了3组特征集的12个模型，发现了有趣的规律：

### 实验设计

| 特征集 | 特征数 | 说明 |
|--------|--------|------|
| **Behavior** | 22个 | 交易行为特征（笔数、金额、时间模式等） |
| **Profile** | 5个 | 账户静态画像（开户时长、地区、类型） |
| **Combined** | 27个 | Behavior + Profile |

### 实验结果

| 特征集 | AUC | 召回率 | Lift | 模型数 |
|--------|-----|--------|------|--------|
| **Combined** | **0.9341** | **57.6%** | **11.51x** | 4个 |
| **Profile** | 0.9243 | 57.6% | 11.51x | 4个 |
| **Behavior** | 0.8162 | 15.3% | 3.05x | 4个 |

### 🔑 关键发现

#### 1. 静态画像是最强信号

```
Profile单独: AUC 0.924 (仅5个特征)
    vs
Behavior单独: AUC 0.816 (22个特征)

结论：账户本身属性比交易行为更具区分性
```

**解释**：
- 涉诈账户可能在**开户阶段**就已经有明显特征
- 地区、开户时间、客户类型等静态属性包含强信号
- 行为特征虽然重要，但增益有限（+1个百分点）

#### 2. Combined策略是最优解

```
Combined (0.9341) > Profile (0.9243) > Behavior (0.8162)
                     ↑                    ↑
              静态画像主导           行为特征补充
```

**推荐策略**：
- ✅ 生产环境使用 Combined 模型
- ✅ 充分利用所有可用信息
- ✅ 行为特征提供额外的1个百分点增益

#### 3. 反直觉发现：召回率相同

| 特征集 | Top5%召回率 |
|--------|------------|
| Combined | 57.6% |
| Profile | 57.6% ← **相同！** |
| Behavior | 15.3% |

**含义**：
- Profile和Combined捕获的是**同一批**风险账户
- 行为特征提升了排序能力（AUC +1%），但没有发现新的风险账户
- 这批风险账户主要通过静态画像区分

## 📈 模型性能详细分析

### 1. ROC-AUC: 0.9341

**含义**：随机抽一个风险账户和一个正常账户，模型有93.4%的概率给风险账户打更高分

**水平评估**：
- 0.90-0.95：优秀模型 ✅
- 0.85-0.90：良好模型
- 0.80-0.85：基线模型
- < 0.80：需要优化

### 2. Top5%召回率: 57.6%

**计算**：
```
Top 5% = 11,087 × 5% = 555 个账户
其中风险账户 = 34 个
召回率 = 34 / 59 = 57.6%
```

**业务解读**：
- ✅ 运营人员审核555个账户，能发现34个真实风险
- ⚠️ 还有25个风险账户（42.4%）分散在剩余的95%中
- 💡 如果放宽到Top10%，召回率会更高（但工作量翻倍）

### 3. 精确率: 6.1%

**为什么这么低？**

这是**极度不平衡场景的正常表现**：

```
原始正样本率: 0.53%
模型精确率:   6.1%
提升倍数:     6.1% / 0.53% = 11.5x ✅
```

**对比**：
- 随机选择：555个预警中有 ~3个命中
- 模型选择：555个预警中有 34个命中
- **效率提升11.5倍**

### 4. Lift: 11.51x

**定义**：Lift = 精确率 / 原始正样本率

```
Lift = 6.1% / 0.53% = 11.51x
```

**业务含义**：
- 使用模型 vs 不用模型，发现风险的效率提升11.5倍
- 在反诈场景中，**Lift > 10x 属于优秀水平** ✅

### 5. Brier Score: 0.0425

**定义**：概率预测的均方误差

```
Brier = mean((预测概率 - 真实标签)²)
```

**水平评估**：
- < 0.05：优秀 ✅
- 0.05-0.10：良好
- > 0.10：需要校准

**含义**：模型的概率输出是校准良好的

## ⚠️ 模型局限性与说明

### 1. 训练模式：Retrospective Static

**当前状态**：
```
training_mode: "retrospective_static"
evaluation_scheme: "stratified-oof-diagnostic"
production_eligible: False
```

**含义**：
- 使用5折分层交叉验证
- 并非严格的时序训练（未按时间切分）
- 标记为非生产资格（实验性模型）

**潜在问题**：
- ⚠️ 可能存在轻微的时间泄露（虽然特征生成严格控制了时间窗口）
- ⚠️ 交叉验证在高度不平衡数据上的评估偏差

**上线阻断项**：
1. `REFERENCE_MODEL_NOT_APPROVED` - 参考模型未经过生产审批流程
2. `NON_TEMPORAL_DIAGNOSTIC_EVALUATION` - 使用的是诊断性评估而非时序评估
3. `LABEL_TIME_MISSING` - 标签缺少`label_available_at`字段

### 2. 样本极度不平衡

```
正样本：59个 (0.53%)
负样本：11,028个 (99.47%)
不平衡比：1:187
```

**影响**：

- 模型已使用`class_weight='balanced'`处理不平衡
